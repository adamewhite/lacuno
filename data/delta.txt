# Format: one entry per line.
#   +word    add to the dictionary

# already verified. Never edit this file without rebuilding the queue.
#
# Keep this file small and justified. Every entry should have a reason: a word
# players repeatedly report as missing, or a word whose presence created a
# genuinely unfair puzzle. Prefer leaving the base list alone.
