# PROCRO solution blocklist
#
# Words that must NEVER be the answer to a daily puzzle.
#
# This is a SOLUTION filter, not a validation filter. Blocked words stay in the
# dictionary and remain perfectly valid to spell: a player who arranges tiles
# into one still gets a glow and can still win. They simply cannot be the word
# the generator built the puzzle around.
#
# That asymmetry is deliberate. Removing them from the dictionary entirely would
# make the game reject words that are unquestionably real, which is the failure
# mode SPEC §5 warns about. Keeping them out of the SOLUTION vocabulary means
# the game never publishes them under our name.
#
# Frequency filtering does not catch these — the problem cases are common words.
# JEW and TIT both appeared in generated puzzles from the "familiar" tier.
#
# Format: one word per line, `#` for comments. Case is ignored.
#
# Categories, roughly:
#   - slurs and ethnic/religious/national identifiers that read as slurs in
#     puzzle context (a bare identity term as "the answer of the day" reads
#     badly even when the word itself is neutral)
#   - sexual and scatological vulgarity
#   - violence, death, and self-harm
#   - medical and bodily terms that would land badly as a daily answer
#
# THIS LIST NEEDS HUMAN REVIEW. It is a starting point assembled for obvious
# cases, not a vetted policy document. Add to it whenever a generated puzzle
# surfaces something uncomfortable — that feedback loop matters more than
# getting the initial list exhaustive.
